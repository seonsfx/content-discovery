# Moving legacy navigators to legacy/legacyNavs folder

Currently signalbuddy process the content and helps to import built-in content.

There are legacy navigators which were used in Classic view but no longer needed.

To prevent legacy navigators from being imported after the migration(navigators are migrated from `Metabase` to `NavigatorDb`), BITS team created a new folder for legacy navigatrs i.e `legacy/legacyNavs`.
